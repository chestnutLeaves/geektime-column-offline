# 内容来源与校验范围

## 已有整理范围

当前内容包含 159 个专栏、6,300 篇文章和 5 份 PDF。原整理记录中只有 12 篇正文成功取得并采用了在线源站版本；其余 6,288 篇没有完成在线正文逐篇核验。源站限流和失败响应不计为通过。

仍有 11 个原始图片 URL 无法恢复，使用明确的占位提示。清单见 `reports/archive/2026-10-14/缺失图片.csv`。备份间的正文差异、目录覆盖依据和原构建检查都保留在历史报告中。

本次目录迁移的文件哈希检查证明的是复制及路径调整没有损坏内容，不能据此声称已与当前源站一比一验证通过。

## 数据与证据目录

| 位置 | 含义 |
| --- | --- |
| `data/manifests/pages.jsonl` | 页面路径、来源、正文和 HTML 校验值，首页生成依赖此文件 |
| `data/manifests/resources.jsonl` | 图片、附件和 PDF 的路径、来源、大小与 SHA-256 |
| `data/manifests/issues.jsonl` | 转换、标签及资源修复问题记录 |
| `data/provenance/` | 源站请求记录、目录发现、资源替换与补图依据 |
| `data/provenance/snapshots/` | 上述依据引用的必要页面与资源快照，保证本地重建可追溯 |
| `data/reviews/` | 人工核对工作簿 |
| `reports/archive/2026-10-14/` | 初始整理和页面迭代时的历史检查结果 |
| `reports/` 根层 | 当前项目最近执行的检查，不与历史结果混称 |

路径均相对当前项目。完整重建只按需读取 `.cache/upstream/` 中固定版本的 bare Git 仓库，日常使用不依赖这些原始仓库。

## 作者与日期

作者和日期的当前维护入口为 `data/course-metadata.json`，共 159 条记录。2026-10-14 人工核对导入了 54 条结果：补入 15 个具体日期、3 个月份，21 条估算时间单独保留；全部专栏已有作者记录，其中 3 处署名冲突暂未合并。

目前 123 项具有明确年份，包括已采用的人工核对结论，不表示这些来源全部在同一轮独立联网核验。字段级来源、原表行号与采用决定保留在每项记录中。

原始表格副本未改写；导入的逐项变更记录保存在历史报告的 `course-metadata-review-2026-10-14.json` 中。首页的“资料来源”链接可查看对应条目的依据与待核实事项。
